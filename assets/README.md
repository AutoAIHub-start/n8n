# Web Design Assets & UI Storage (웹 디자인 및 UI 자산 저장소)

## 1. 개요 (Overview)
- 본 디렉토리(`assets/web-design/`)는 크로스보더 무역 자동화 시스템의 웹 디자인 봇(`@AppWebDev1_bot`)이 활용하는 UI 레이아웃 레퍼런스, 디자인 가이드, 시각 자료 및 템플릿을 보관하는 공간입니다.

## 2. 주요 보관 자료
- 다국어(i18n) 반응형 UI 레이아웃 스키마
- Flexbox / Grid 기반 CSS/HTML 템플릿 구조
- 중동 및 글로벌 타겟 맞춤형 폰트 및 비주얼 스타일 가이드

## 3. 관리 지침
- 디자인 변경 사항 및 시각 자료 업데이트 시 본 디렉토리에 파일을 추가하고 Git 히스토리를 동기화합니다.
